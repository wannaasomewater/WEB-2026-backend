# WEB-2026-backend

Бэкенд для системы оценки электромагнитного излучения от бытовых приборов

## Тема проекта
Система расчета плотности потока мощности (ППМ) электромагнитного излучения от бытовых приборов в квартире и сравнения с санитарными нормами.

## Сущности системы
- **Приборы (Devices)**: холодильник, СВЧ-печь, Wi-Fi роутер и другие бытовые устройства
- **Заявки (Calculations)**: расчет ППМ в точке нахождения человека для списка устройств с указанием расстояния
- **Пользователи (Users)**: создатели заявок и модераторы

## Технологии
- NestJS
- TypeScript
- PostgreSQL
- Minio (для хранения изображений)
- Redis (для сессий)
- Swagger (документация API)
