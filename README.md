# WEB-2026-backend

Бэкенд для системы оценки электромагнитного излучения от бытовых приборов

## Тема
Оценка электромагнитного излучения от устройств в квартире. Услуги - бытовые приборы (холодильник, СВЧ-печь, Wi-Fi роутер), их мощность. Заявка - расчет плотности потока мощности (мкВт/см²) в точке нахождения человека и сравнение с санитарными нормами.

## Технологии
- FastAPI
- Jinja2
- SQLAlchemy + Alembic
- MinIO (хранение медиафайлов)
- PostgreSQL (с ЛР2)

## Установка
python3 -m venv emf_devices_venv
source emf_devices_venv/bin/activate
pip install -r requirements.txt

## Запуск
python main.py

## Страницы
- / - список приборов (плитка)
- /draft - черновик прибора
- /device/{id} - лента прибора
- /device/{id}?next=true - следующий прибор
